# 管理后台系统

基于 Vue 3 + Element Plus 的现代化管理后台系统，提供完整的用户管理、内容管理、权限管理和系统设置功能。

## 技术栈

- **前端框架**：Vue 3 + Vite
- **UI 组件库**：Element Plus
- **状态管理**：Pinia
- **路由**：Vue Router 4
- **数据可视化**：ECharts
- **HTTP 客户端**：Axios
- **日期处理**：Day.js

## 核心功能

### 1. 数据仪表盘
- 统计卡片：总用户数、总内容数、今日访问量、系统运行时间
- 用户增长趋势图表
- 内容分类分布图表
- 最近活动列表

### 2. 用户管理
- 用户列表展示
- 添加/编辑/删除用户
- 用户状态切换
- 按用户名、状态、注册时间搜索
- 分页功能

### 3. 内容管理
- 内容列表展示
- 添加/编辑/删除内容
- 内容分类管理
- 内容状态管理（发布/草稿/回收站）
- 封面图上传
- 按标题、分类、状态、发布时间搜索

### 4. 角色管理
- 角色列表展示
- 添加/编辑/删除角色
- 权限分配（菜单权限）

### 5. 菜单管理
- 菜单树结构展示
- 添加/编辑/删除菜单
- 子菜单管理
- 菜单排序

### 6. 系统设置
- 系统配置：系统名称、版本、描述、版权信息等
- 参数管理：添加/编辑/删除系统参数
- 系统日志：操作记录、搜索筛选


## 安装与运行

### 1. 安装依赖

```bash
npm install
```

### 2. 启动开发服务器

```bash
npm run dev
```

访问 http://localhost:5173/ 查看效果（端口可能会自动调整）。

### 3. 构建生产版本

```bash
npm run build
```

### 4. 预览生产构建

```bash
npm run preview
```

## 代码规范

- 使用 Vue 3 `<script setup>` 语法糖
- 遵循 ESLint + Prettier 代码规范
- 组件命名使用 PascalCase
- 变量命名使用 camelCase
- 函数命名使用 camelCase
- 常量命名使用 UPPER_CASE

## 注意事项

1. 本项目使用 mock 数据模拟后端接口，实际部署时需要替换为真实的 API 接口
2. 所有表单验证已在前端实现，后端也需要相应的验证逻辑
3. 权限管理功能需要后端配合实现完整的权限控制
4. 生产环境部署时请修改相关配置信息
